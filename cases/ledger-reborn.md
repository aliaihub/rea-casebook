# Ledger Reborn: an independent desktop accounting implementation

Category: Applications

Evidence: **Public project** · Stage: **Working implementation**

Last source review: 2026-10-14

## Target and question

Study QuickBooks Desktop for Mac workflows and implement an independent local accounting application.

## REA workflow and result

The maintainer explicitly documents using REA. Public source implements a SQLite ledger, invoices, payments, inventory, bank reconciliation, and reports, with test fixtures and platform build recipes.

## Evidence and limits

The project is a preview with major omitted workflows. Public synthetic checks and the author’s private comparisons with original reports have different scopes. We reviewed the README, not the application or test execution.
