# DX-Ball: recovering positional audio

Category: Games

Evidence: **Official documented case** · Stage: **Partial reconstruction**

Last source review: 2026-10-14

## Target and question

Recover the position-to-pan calculation in DX-Ball 1.07.

## REA workflow and result

REA-assisted native inspection leads to a small C reconstruction. The official case reports 3,205 original-x86 comparisons and agreement with all 63 compiled function bytes.

## Evidence and limits

Those checks cover a particular function. The wider game reconstruction is a separate, ongoing project; this collection has not executed its tests.
