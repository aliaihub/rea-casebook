# ReaCut: a video editor informed by CapCut research

Category: Applications

Evidence: **Public project** · Stage: **Working implementation**

Last source review: 2026-10-14

## Target and question

Use REA-assisted local behavior and format research to build an independent video editor.

## REA workflow and result

The public project documents a desktop timeline, subtitles, transitions, keyframes, export, and a Codex integration, along with REA research records and validation documentation.

## Evidence and limits

This is a preview with scoped experimental CapCut draft import. It is not full CapCut compatibility; cloud sync and several AI features are absent. We reviewed project documentation without building or running the editor.
