# zee-rp: making Axure prototype files scriptable

Category: Applications

Evidence: **Public project** · Stage: **Working implementation**

Last source review: 2026-10-14

## Target and question

Read and edit supported Axure RP 11 documents through scripts and an MCP interface.

## REA workflow and result

The public toolkit provides a binary codec, object-reference handling, template cloning, and scoped document editing. The discovery collection links author posts explicitly attributing REA assistance.

## Evidence and limits

The README was reviewed directly; REA attribution was found through the discovery collection, and those social posts were not independently inspected. Native acceptance is documented for a particular macOS/Axure build. Structural parsing, native loading, preview, and editing are distinct checks. No tests were run here.
