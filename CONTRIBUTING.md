# Contributing

Submit a case, a correction, or stronger evidence through an issue or pull request.

## Selection

- Include a concrete target and a specific investigation or result.
- Link evidence that REA was used. Generic AI rebuilds and REA installation guides do not qualify.
- Prefer original authors, public code, research records, and test artifacts.
- Author reports are welcome when clearly labeled. Plans without results belong in discussions, not the casebook.
- Explain what was learned or rebuilt, and what remains unknown. Never turn a function recovery into a claim of a complete application reconstruction.
- Credit the original author and any collection that helped discover the case.
- Do not submit proprietary binaries, credentials, private data, or unlicensed assets.

## Case format

Create `cases/descriptive-slug.md` using `cases/TEMPLATE.md`, and add a row to the matching README category. Use concise English and direct source links.

Record the date sources were checked. Distinguish source inspection from running the project. Only use **Independently reproduced** when a reviewer has executed the documented procedure and provides their environment and results.

Before submitting, check links, scope, attribution, and duplicate targets. Several investigations of the same application can share one page when they cover the same result.
